FORCEFORGE X — PERMANENT VERSION HISTORY
========================================

Policy
------
This is the sole version changelog in the repository.
Language: English only.
Location: /CHANGELOG.txt
Format: version, date, branch/PR, type, changes, validation, limitations.
Never delete or rewrite an earlier entry. Add corrections as a new dated entry.
Document branch-only releases explicitly: a draft PR is not a main-branch release.
The engineering application must preserve previous verified behavior.
Any future UI or engineering release must append its complete change description
to this same file in the same versioned commit or PR.

Version numbering note
----------------------
Engineering and UI feature branches evolved in parallel. UI v0.4 and UI v0.5
labels below do not denote merges of corresponding engineering versions.
The records were reconstructed from retained GitHub PR descriptions and the
previous docs/CHANGELOG.md on 2026-11-14. Exact tests for past branches were
reported by their authors; no retroactive browser validation is claimed.

UI VERSION 0.1.0 — FULL INTERFACE REBUILD REVISION — 2026-11-14
PR: #11 | Branch: ui/v8-forge-studio
Engineering foundation: v0.7 tetra10 FEA + v0.4 measured modal study
Type: UI v0.1 redesigned implementation; draft, not merged
========================================================================
Design and interaction
- Rebuilt the original UI v0.1 into an object-centered CAD/CAE experience
  informed by professional feature trees and mode-specific property controls.
- Introduced an authored precision-industrial design language with technical
  typography, compact scientific HUD, restrained high-contrast materials,
  coherent visual hierarchy and improved model-stage balance.
- Replaced generic dashboard thinking with a CAD-like object explorer, a
  scene-context card, focused analytical inspector and immersive panel mode.
- Added interaction shortcuts: F toggles immersive mode, R resets the camera,
  and 1 / 2 switches the supported engineering workspaces.
Rendering and model presentation
- Added studio/viewport3d.js: original WebGL2 rendering engine for the actual
  Python-returned FEM mesh surface triangles, normals, picked lab sensor
  positions, GPU wireframe overlay and color-mapped solid von Mises samples.
- Added isometric/front/right/top camera controls, responsive orbit/zoom,
  model selection, source sensor inspection, and optional true-proportion view.
- Kept the original Canvas renderer as fallback if WebGL2 is unavailable.
- Reframed the slender 1,524 mm Hannover physical beam by enlarging the
  displayed section width/thickness 24x only for visual inspection, with
  an explicit visible exaggeration label and a true-scale toggle. Numerical
  geometry, published elevations and solver data were not modified.
- Removed a distracting overlay grid drawn on top of the model surface.
Engineering fidelity and compatibility
- Show stress visualization only in the actual tetra10 3D solid workspace;
  real-laboratory modal mode instead exposes Mode Shape / Geometry / Sensors.
- Retained the existing modal calibration, held-out checks, source evidence,
  parameter sliders, 3D candidate redesign and physical FEM solver modules.
- Kept the laboratory's physical measured frequencies separate from assumed
  material constants and computed FE values.
- The 3D solid is a computational benchmark, not an experimentally validated
  manufactured specimen; no safety qualification is claimed.
Testing and documentation
- Added WebGL engine to the local HTTP asset allowlist.
- Extended CI JavaScript syntax checks to both app.js and viewport3d.js.
- Extended studio regression tests for 3D renderer assets, object explorer,
  version metadata and UI controls.
- Updated README with Mac guidance, new UX flow, shortcuts and Safari
  acceptance steps.
- All notes are English and appended to this sole CHANGELOG.txt. Earlier
  engineering and UI history is preserved verbatim.
Validation status
- GitHub CI numerical regression and JavaScript syntax checks required.
- macOS Safari visual quality, camera performance and UX still require
  direct review; no browser visual acceptance is claimed.
- The existing v0.1 rollout remains a Draft PR pending those checks.

VERSION 0.8.0 — 2026-11-14
Branch: ui/v8-forge-studio
Base: feature/3d-solid-tet10-v7 (engineering v0.7)
Type: Original UI/UX redesign and presentation API; draft, not merged
========================================================================
Design
- Introduced ForceForge X Studio, an original, model-first visual system.
- Replaced stacked dashboard assumptions with a dominant orbitable 3D canvas,
  narrow tool rail, collapsible parameter tray, contextual live inspector
  and expandable results/evidence drawer.
- Added an intentional graphite material palette, luminous lime-green
  highlights, refined typography, scale, spacing and purposeful state changes.
- Added custom responsive web UI using studio/index.html, styles.css and app.js.
- Designed to be visually distinct rather than imitate Apple or other brands.
Engineering integration
- Introduced studio_server.py, a localhost-only Python HTTP bridge reusing
  forceforge/modal_benchmark.py and forceforge/solid3d.py without rewriting
  physical simulation code.
- Added two real working modules: parametric tetra10 volume FEA and published
  laboratory modal correlation.
- Added model orbit, zoom, camera reset, stress/form/mesh visualization,
  source sensor markers, and live recomputation of FE results on input changes.
- Added one-parameter calibration against measured Mode 1, with independently
  reported holdout errors on Modes 2 and 3.
- Added nine-candidate 3D solid re-meshing and numerical redesign with current
  model constraints, result inspection and evidence/source access.
- Preserved existing Streamlit specialist pages and numerical solver code.
Version history
- Consolidated the existing Markdown change log and known version history
  into this root-level English-only CHANGELOG.txt.
- Retired docs/CHANGELOG.md as a second changelog.
Engineering integrity
- Measured published modes remain distinct from computed frequencies.
- Original 3D parametric solid is NOT a physically validated static specimen.
- Deformation exaggeration is labeled as visualization only.
- The source-attributed CAD reconstruction is not an original author mesh.
- No structural certification, arbitrary CAD meshing, plasticity or CFD claim.
Validation
- Static code and interaction tests introduced in tests/test_studio.py.
- Browser/Safari visual acceptance and real-host performance verification
  remain required before merging.
- No actual runtime or GitHub Actions pass is claimed in this release note.
