FORCEFORGE X — PERMANENT VERSION HISTORY
========================================

Policy
------
This is the sole version changelog in the repository.
Language: English only.
Location: /CHANGELOG.txt
Format: version, date, branch/PR, type, changes, validation, limitations.
Never delete or rewrite an earlier entry. Add corrections as a new dated entry.
Document branch-only releases explicitly: a draft PR is not a main-branch release.
The engineering application must preserve previous verified behavior.
Any future UI or engineering release must append its complete change description
to this same file in the same versioned commit or PR.

Version numbering note
----------------------
Engineering and UI feature branches evolved in parallel. UI v0.4 and UI v0.5
labels below do not denote merges of corresponding engineering versions.
The records were reconstructed from retained GitHub PR descriptions and the
previous docs/CHANGELOG.md on 2026-11-14. Exact tests for past branches were
reported by their authors; no retroactive browser validation is claimed.

Branch: ui/v0.2-adaptive-spatial | Draft PR #13

Type: Spatial coordinates, reference grid and context-aware surface probing
========================================================================
- Restored a clear model-aligned X/Y reference grid and three distinct
  world-coordinate axes in the actual WebGL scene with depth testing.
- Added a view-responsive XYZ orientation compass for reliable camera
  interpretation after rotation and zoom.
- Added hover inspection of rendered 3D triangle surfaces with actual
  perspective-aware barycentric sampling and frontmost face selection.
- On cursor hover, show reference-position XYZ in millimeters, plus
  available computed local state, in a compact, cursor-near data card.
- For true volumetric 3D solid and actual STEP/Gmsh tetra10 models,
  expose the FEM reference mesh and unscaled nodal displacement separately
  from display-only exaggerated deformation. Inspectors interpolate
  nodal displacement and show per-surface-face stress sampled from the
  original finite-element result (MPa).
- For the published real laboratory modal beam, the original undeformed
  geometry is shown as the coordinate reference. Frequencies remain
  global measured/computed modal values, not fabricated local measurements.
- In the hypothetical static beam case, expose FEM nodal displacement
  without the visualization multiplier; modal display-amplitude values are
  never labeled as real local displacements.
- Grid, axis labels and hover cards remain readable and compact in smaller
  browser windows; hover does not replace existing physical model controls.
- The XYZ triad is anchored at the actual world origin (0, 0, 0), and
  reference grid lines align to integer multiples of the displayed step.
- Toggling true laboratory cross-section proportions rebuilds the grid;
  pending FEA updates hide hover cards until the new solve is complete.
- Added JavaScript syntax coverage for the new studio/inspection.js module,
  tests for FEM reference/displacement fidelity, and original data linkage.
- Preserved all engineering v0.8 STEP import, CAD revision, lab, industry,
  robust optimization and ML modules; solver algorithms are unchanged.
- No arbitrary-point stress interpolation or physical measurement at the
  hovered location is claimed. Stress is an originating face/element sample.
- Kept this CHANGELOG.txt as the only permanent English version log.
  Every earlier version entry is retained without deletion.
